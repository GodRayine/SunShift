# Подготовка анкеты IARC

Цель: приложение для всех возрастов, без возрастных ограничений по собственному
контенту. 7 октября 2026 анкета IARC 10.3 заполнена и сохранена в Partner Center:
Россия (PCBP) 0+, ESRB Everyone, PEGI 3+, IARC и Microsoft Store 3+,
USK Everyone, Бразилия Livre, Чили TE. Rating ID пока Pending; продукт ещё
не отправлен на сертификацию. Рейтинги региональные, единое «0+» для всех
стран не заявляется. Условия IARC приняты после явного подтверждения владельца.

Это факты для ответов на реально отображённые вопросы, а не готовый сертификат:

| Содержание / функция | Ответ по SunShift 0.5.0 |
| --- | --- |
| Тип продукта | Утилита персонализации, не игра и не социальная сеть |
| Насилие, кровь, страх | Нет |
| Секс, обнажение, сексуальный контент | Нет |
| Ненормативная лексика, дискриминация | Нет |
| Алкоголь, табак, наркотики | Нет |
| Азартные игры, ставки | Нет |
| Реклама, покупки, случайные платные предметы | Нет |
| Общение и обмен контентом между пользователями | Нет |
| Публикация пользовательских материалов | Нет; файлы используются локально |
| Передача текущей физической позиции другим пользователям | Нет |
| Доступ приложения к геопозиции | Да, по разрешению Windows, только в памяти сеанса |
| Генеративный ИИ в приложении | Нет |
| Встроенный свободный просмотр интернета | Нет; внешние ссылки открываются браузером |

Если вопрос говорит о доступе к координатам, отвечать «да», даже несмотря на отсутствие
сохранения. Если он спрашивает именно обмен с другими пользователями — «нет».
Собственные локальные картинки пользователя не распространяются приложением;
в комплекте и карточке нет материалов для взрослых. Приложение общего назначения,
специально на детей не ориентировано. Все поля анкеты нужно читать вместе с подсказками.

После заполнения нажать Save and generate и сохранить полученные региональные
рейтинги. Только этот результат использовать в карточке. Изменение рейтинга —
через редактирование анкеты / обращение IARC.

[Официальная инструкция IARC для MSIX](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msix/age-ratings).
