# Карточка Microsoft Store — ru-RU

## Название

SunShift

## Краткое описание

Дневные и ночные обои по рассвету и закату вашего региона.

## Описание

SunShift помогает рабочему столу жить в ритме солнца. Выберите дневные и ночные
изображения: приложение определит местоположение компьютера через Windows,
рассчитает часовой пояс, рассвет и закат и переключит фон в подходящий момент.

Для разнообразия настройте отдельную коллекцию. Можно выбрать папки с обоями
для дня и ночи или собрать связанные пары одной сцены. Дополнительный таймер
меняет изображения с выбранным интервалом, сохраняя переключение по солнцу.

Приложение работает в трее. Интерфейс поддерживает светлую, тёмную и системную
тему и использует акцентный цвет Windows. Автозапуск включается по вашему выбору.

Координаты используются только в памяти текущего сеанса и не передаются
разработчику. Расчёт выполняется локально. При новом запуске Windows определяет
позицию заново. Если геолокация недоступна, можно ввести координаты вручную;
после полного выхода их потребуется ввести повторно. В настройках можно полностью
отключить использование местоположения и применять обои вручную.

Изображения выбираете вы: встроенного каталога или загрузки обоев нет. Обои
экрана блокировки необязательны; если их не выбрать, текущий фон сохраняется.
Windows может ограничить смену экрана блокировки настройками персонализации или
политиками устройства. Автоматическое переключение выполняется, пока SunShift
запущена; после сна расчёт обновляется. Служба геолокации Windows может использовать
сеть согласно системным настройкам.

SunShift — свободная программа под GNU GPL версии 3 или более поздней.

## Возможности

- Дневные и ночные профили по рассвету и закату.
- Фон рабочего стола и необязательный фон экрана блокировки.
- Отдельные папки с обоями для дня и ночи.
- Связанные пары «день + ночь».
- Интервалы 1, 5, 15, 30 минут; 1, 2, 4, 8, 12 часов; раз в день, а также свой интервал.
- Последовательный или случайный порядок коллекции.
- Светлая, тёмная и системная тема.
- Геолокация Windows либо ручные координаты на текущий сеанс.
- Работа в трее, управляемый автозапуск и кнопка полного выхода.
