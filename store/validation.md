## Оставшаяся проверка на устройстве

1. Установка, запуск с package identity и удаление проверены. Остаётся обновление
   установленной предыдущей версии на новую и проверка в «Параметры → Приложения».
2. В установленном приложении проверить реальный системный запрос геопозиции:
   разрешить, отказать, отменить доступ в параметрах, повторно разрешить.
   Позиция после отказа не должна отображаться или использоваться. Проверить
   запуск с сохранённой автоматикой: новое определение позиции, без данных на диске.
3. На тестовом профиле Windows проверить реальную смену рабочего стола / блокировки,
   пустой экран блокировки, отказ персонализации, сон / пробуждение и переход солнца.
   Проверять на профиле с тестовыми обоями, чтобы не менять личную персонализацию.
4. Включение Windows StartupTask и его удаление вместе с пакетом проверены.
   Остаются запуск в трее после входа, запрет из «Автозагрузка», отказ программы
   обходить запрет, выключение.
5. Файловые проверки WACK уже пройдены. После изменения исполняемых файлов,
   манифеста или ресурсов пересобрать MSIX и повторить WACK с новым путём отчёта.
6. Проверить установку обновления, удаление и отсутствие startup task после удаления.
   Проверить на минимально заявленной Windows и при масштабировании 125 / 150 / 200%.
   Минимум манифеста 10.0.19041 — граница API, пока не подтверждение испытания этой ОС.
7. Карточка Gordry.SunShift, политика, скриншоты, IARC и объяснение runFullTrust
   сохранены. После подтверждения аккаунта разработчика отправить на сертификацию.
   Только результат Microsoft означает принятие Store.
