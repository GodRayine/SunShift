# Испытание установленного MSIX, 7 октября 2026

Windows 11 Pro 10.0.28000, x64. Это промежуточный отчёт:
полная проверка перед Store ещё не завершена.

## Выполнено

- Создана локальная копия исходного Store MSIX с одноразовой тестовой подписью
  того же Publisher. Оригинал остался неподписанным и неизменным:
  SHA-256 `80ed325e67793cc42e6d41ed66cb62aa3b7bfe34a20f99731e555e164fdf7dca`.
- Через Windows PowerShell от администратора добавлено временное доверие только
  этому сертификату в LocalMachine/TrustedPeople; тестовая копия установлена.
- Windows зарегистрировала `Gordry.SunShift_0.5.0.0_x64__ys6nas4vd5rvm`, Status=0.
- Приложение запущено через App ID `Gordry.SunShift_ys6nas4vd5rvm!App`.
  Процесс работал из установленного каталога WindowsApps; диагностика Packaged=true.
- Windows вернула реальную геопозицию. Интерфейс отобразил соответствующий регион,
  время, рассвет и закат. Координаты не включены в этот отчёт.
- После изменения настройки автоматики ManualPoint и LastLocation отсутствуют
  в settings.json. Автоматика была поставлена на паузу для испытания.
- Переключатель «Запускать с Windows» зарегистрировал штатный StartupTask:
  State=2 (Enabled), UserEnabledStartupOnce=1.
- Тестовый пакет удалён через Remove-AppxPackage; регистрация его StartupTask
  тоже удалена. Закрытый ключ и одноразовый сертификат удалены.
- Исходные settings.json, путь / содержимое фонового изображения и его режим
  восстановлены и сверены. Пользовательский автозапуск portable не удалялся.

## Не подтверждено

Отказ и отзыв геопозиции через настоящий системный интерфейс; появление первого
запроса разрешения (Windows уже разрешила чтение); установка другого фона блокировки;
сон / пробуждение; вход в Windows с StartupTask; системный запрет автозапуска;
обновление версии; минимальная заявленная Windows; масштабы 150 / 200%; отправка.
Подставные интеграционные проверки этих сценариев не считаются реальными испытаниями.

Продолжение взаимодействия с окнами остановлено инструментом Computer Use:
он не смог надёжно определить URL обычного Chrome для применения своей политики.
Открытие Edge отдельной командой тоже отклонено автоматической проверкой разрешений
с причиной `blocked by policy`. Это не ошибка SunShift и не доказательство блокировки
со стороны антивируса. Проверки аутентификации Microsoft выполняются владельцем.

После остановки тестовая установка и доверие сертификату убраны, исходное состояние
персонализации восстановлено. Данные испытания находятся локально в
`../artifacts/store-checks/local-tests/`; личные снимки и настройки не публикуются.

Позднее владелец вошёл в Partner Center во встроенном браузере. Карточка и IARC
сохранены; все разделы Complete. Отправка блокируется подтверждением аккаунта
разработчика. Подробности: `partner-center-2026-10-07.md`.
