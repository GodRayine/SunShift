# SunShift — новая разработка

Цель: геопозиция ПК → географический часовой пояс → рассвет и закат в этой точке
→ состояние «день»/«ночь» → выбранные изображения рабочего стола и экрана блокировки.
Пользователь задаёт только дневные и ночные изображения. Геозон и радиусов нет.

1. **Астрономическое ядро.** Расчёт положения солнца по формулам NOAA/Meeus,
   восход/закат при высоте центра солнца −0,833°. Все сравнения времени в UTC.
   Критерии: сверка с USNO, границы дня, разные полушария, полярные условия,
   линия смены дат, летнее время и независимость от часового пояса Windows.
2. **Регион по координатам.** Встроенная GeoTimeZone + правила TimeZoneInfo.
   Расчёт без веб-сервисов. Критерий: Москва, Нью-Йорк, Сидней, Новая Зеландия
   определяются по координатам; время на экране показано в найденном регионе.
3. **Windows.** Геолокация Windows, фон через Win32, блокировка через WinRT.
   Критерий: независимые результаты двух экранов, повтор ошибок, отсутствие
   повторных записей уже применённого файла, отмена при паузе.
4. **Минимальный интерфейс.** Состояние солнца, местное время, рассвет, закат,
   следующее переключение; четыре изображения в двух профилях. Цвета Windows.
   Критерий: нет ручных геозон, ясный первый запуск, предпросмотр и валидация.
5. **Фоновая работа.** Проверка солнца каждые 30 секунд, координат каждые 5 минут;
   пересчёт после сна. Трей, добровольный автозапуск, сохранение настроек.
   Критерий: расчёт работает по последней позиции при кратком сбое геолокации,
   показывает возраст позиции, не использует координаты старше 24 часов.
6. **Поставка.** Сценарные тесты, Release, переносимый EXE, визуальная проверка
   обеих тем без изменения обоев. Инструкция с проверенными ограничениями.

При первом запуске автоматика выключена. Можно задать координаты вручную, если
Windows не предоставляет геопозицию. Полярный день/ночь определяются положением
солнца, а не фиктивным временем «06:00–18:00».

## Проверенный результат

- Новая программа реализована в отдельном проекте SunShift; модели геозон в ней нет.
- Release-сборка без ошибок/предупреждений. Пройдены все 27 сценарных тестов.
- Восход/закат сверены с независимыми данными USNO для трёх городов.
- Визуально проверены обе темы, день/ночь, первый запуск, полярные состояния
  и окно координат. Переносимый EXE прошёл проверки запуска с кодом выхода 0.
- Готовые файлы: `artifacts/portable-win-x64/SunShift.exe`, `artifacts/SunShift-win-x64.zip`.
- API блокировки на компьютере разработки сообщил `IsSupported = true`.
  Реальные разрешения геолокации и изменение обоев не запрашивались при проверке.
