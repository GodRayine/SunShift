# SunShift — новая разработка

Цель: геопозиция ПК → географический часовой пояс → рассвет и закат в этой точке
→ состояние «день»/«ночь» → выбранные изображения рабочего стола и экрана блокировки.
Пользователь задаёт только дневные и ночные изображения. Геозон и радиусов нет.

1. **Астрономическое ядро.** Расчёт положения солнца по формулам NOAA/Meeus,
   восход/закат при высоте центра солнца −0,833°. Все сравнения времени в UTC.
   Критерии: сверка с USNO, границы дня, разные полушария, полярные условия,
   линия смены дат, летнее время и независимость от часового пояса Windows.
2. **Регион по координатам.** Встроенная GeoTimeZone + правила TimeZoneInfo.
   Расчёт без веб-сервисов. Критерий: Москва, Нью-Йорк, Сидней, Новая Зеландия
   определяются по координатам; время на экране показано в найденном регионе.
3. **Windows.** Геолокация Windows, фон через Win32, блокировка через WinRT.
   Критерий: независимые результаты двух экранов, повтор ошибок, отсутствие
   повторных записей уже применённого файла, отмена при паузе.
4. **Минимальный интерфейс.** Состояние солнца, местное время, рассвет, закат,
   следующее переключение; четыре изображения в двух профилях. Цвета Windows.
   Критерий: нет ручных геозон, ясный первый запуск, предпросмотр и валидация.
5. **Фоновая работа.** Проверка солнца каждые 30 секунд, координат каждые 5 минут;
   пересчёт после сна. Трей, добровольный автозапуск, сохранение настроек.
   Критерий: расчёт работает по последней позиции при кратком сбое геолокации,
   показывает возраст позиции, не использует координаты старше 24 часов.
6. **Поставка.** Сценарные тесты, Release, переносимый EXE, визуальная проверка
   обеих тем без изменения обоев. Инструкция с проверенными ограничениями.

При первом запуске автоматика выключена. Можно задать координаты вручную, если
Windows не предоставляет геопозицию. Полярный день/ночь определяются положением
солнца, а не фиктивным временем «06:00–18:00».

## Проверенный результат

- Новая программа реализована в отдельном проекте SunShift; модели геозон в ней нет.
- Release-сборка без ошибок/предупреждений. Пройдены все 29 сценарных тестов.
- Восход/закат сверены с независимыми данными USNO для трёх городов.
- Визуально проверены обе темы, день/ночь, первый запуск, полярные состояния
  и окно координат. Переносимый EXE прошёл проверки запуска с кодом выхода 0.
- Готовые файлы: `artifacts/portable-win-x64/SunShift.exe`, `artifacts/SunShift-v0.4.2-win-x64.zip`.
- API блокировки на компьютере разработки сообщил `IsSupported = true`.
  Реальные разрешения геолокации и изменение обоев не запрашивались при проверке.

## Версия 0.2.0 — рабочий дизайн

- Дизайн UI Lab перенесён в основной Windows-интерфейс.
- Реальные службы геолокации, смены фонов, автозапуска и сохранения подключены
  к новым контролам. Экспериментальный UI Lab удалён после переноса дизайна.
- Начальное состояние редактора соответствует солнцу; выбранный пользователем
  профиль сохраняется при обновлении расчёта. Вкладка не меняет системные обои.
- Состояния автоматики: «Включена / На паузе». Применение выбранного профиля
  ставит автоматику на паузу. Пустое поле сохраняет соответствующий фон.
- Настройки 0.1.0 совместимы; добавлено сохранение предпочтения темы.
- 14 проверок основного окна с изолированными службами подтверждают маршрутизацию
  автоматической и ручной смены, редактирование, сохранение, отказ геолокации и темы.

## Версия 0.3.0 — пулы и интервал

- Папки для двух экранов внутри дневного/ночного профиля, с сохранением
  одиночных изображений как альтернативного источника.
- Интервал 1–1440 минут и последовательный/случайный порядок. Солнечный
  переход немедленный; просыпание не вызывает перебора пропущенных смен.
- Критерии: отсутствие повторных записей до срока, случайный кадр без повтора,
  независимость профилей, сохранение фона при недоступной папке, обнаружение
  добавления/удаления файлов, пропуск повреждённых кадров, ограниченный кэш,
  исходные картинки не изменяются, старые настройки совместимы.
- Проверка: 42 теста ядра/настроек и 30 изолированных сценариев основного окна.
- Светлая/тёмная тема, настройка пула и узкое окно с текстом 125% проверены.

## Версия 0.4.0 — отдельная коллекция и пары

1. Вынести папки и таймер из редактора профиля в дополнительную коллекцию.
   Критерий: отключение таймера сохраняет смену день/ночь; основная пауза
   останавливает все автоматические изменения. Настройки 0.3.0 совместимы.
2. Добавить режим связанных пар. Критерий: на рассвете/закате сохраняется ID
   сцены; по таймеру меняется вся пара. ID сохраняется при перезапуске.
   Поддержать последовательный/случайный порядок, сон, перевод часов и отмену.
3. Объединить название и оконные кнопки с основным окном. Критерий: работают
   нативное перетаскивание, изменение размера, сворачивание и разворачивание.
4. Проверить темы и узкий редактор с крупным текстом, обновить инструкции
   и собрать переносимый вариант с исходниками.

Результат: 52 теста, 43 изолированных проверки приложения; Release без
предупреждений и ошибок. Реальные системные обои при проверках не менялись.
